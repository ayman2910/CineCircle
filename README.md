# CineCircle

Social movie and TV discovery, watch-tracking, and group recommendation web app built for CSE470 (Group 4).

## Tech Stack
- Java 21, Spring Boot MVC, Spring Security
- Spring `JdbcTemplate` + PostgreSQL (Neon)
- Thymeleaf + Vanilla CSS/JS
- TMDB API v3
